# ADRs

Use this folder for short architecture decision records when named alternatives matter.

An ADR is warranted when the project makes a non-obvious decision between alternatives such as:

- Kuzu vs another graph store
- Qdrant vs pgvector
- section-level vs abstract-level embeddings first
- local file artifacts vs early database-first persistence
- rule-based link promotion vs LLM-assisted link promotion

Keep ADRs short, practical, and tied to concrete decisions.
