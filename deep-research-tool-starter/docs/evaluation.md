# Evaluation

## Philosophy

This project should not stop at "looks useful."

It should gradually build an evaluation layer that measures:

- retrieval quality
- support quality
- citation grounding
- contradiction handling
- semantic-link precision
- report usefulness

## Likely Evaluation Artifacts

- gold queries
- expected support passages
- regression checks
- groundedness checks
- semantic-link review sets
- error analysis notes

## Evaluation Growth Model

- early phases: manual review and small gold sets
- middle phases: repeatable retrieval checks
- later phases: regression harnesses and support-quality scoring

## Key Principle

The system should eventually be able to explain:

- where it works
- where it fails
- what is explicit support
- what is semantic suggestion
