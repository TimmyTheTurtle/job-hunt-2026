# Forward Deployed Engineering Exploration

Created: 2026-07-23

This directory is a separate exploration track for using Forward Deployed Engineering as a
pragmatic first island.

The goal is not to replace the repo's main Applied AI Systems Engineer positioning.
The goal is to test whether engineering-heavy FDE / AI solutions / implementation roles are:

- easier to win in the near term,
- more profitable in the near term,
- compatible with the longer-term applied AI systems direction,
- and narrow enough to avoid drifting into soft pre-sales or customer-success-only work.

## Working Thesis

Use FDE as an entry vector, not as the final identity.

Near-term sell:

> Systems-minded software engineer who can enter messy real environments, translate ambiguity
> into working systems, integrate tools, debug blockers, and ship useful AI-enabled workflows.

Long-term direction remains:

> Applied AI systems engineering around document-heavy, compliance-sensitive, and evidence-driven
> workflows.

## Decision Rule

This exploration is successful if it produces one or more of:

- more plausible interview traction than the current pure applied-AI-core framing,
- stronger compensation opportunities,
- faster conversion of existing evidence into market-legible applications,
- and a path that still compounds toward deeper applied AI systems work.

This exploration is not successful if it mostly pulls toward:

- demo-driven sales engineering,
- customer success with light scripting,
- travel-heavy field work with weak code ownership,
- or generalist services work that does not strengthen the long-term technical story.
