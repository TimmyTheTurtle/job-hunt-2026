# Retired: ATS and Startup Sweep

This is no longer an active workflow. The repository now uses user-configured
Gmail job alerts as its sole job-discovery channel.

Do not search Ashby, Greenhouse, Lever, YC, Hacker News, startup boards, or
direct careers pages for new roles unless the user explicitly changes that
policy or asks for historical/diagnostic work on this retired workflow.

The file is retained as a historical record of the former discovery approach.
Any role found through an explicitly authorized diagnostic must still pass
the current Gmail/full-posting/deep-dive and application-record rules before
it can affect a tracker or application record.
