# Retired: Contract Search

This is no longer an active workflow. The repository now uses user-configured
Gmail job alerts as its sole job-discovery channel, including contract,
consulting, fractional, and short-term opportunities when those arrive in
Gmail.

Do not run the former contracting profile or perform a separate contract
marketplace/ATS search unless the user explicitly changes the Gmail-only
policy or requests historical/diagnostic work.

The file is retained as a historical record of the former contract-search
approach. Any explicitly authorized lead must still pass the current Gmail
link-recovery, full-posting verification, deep-dive, and application-record
rules before it can affect a tracker or application record.
