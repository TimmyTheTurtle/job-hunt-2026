# Job Search Strategy — Simulation / Systems / Game Engineering

## Positioning

Do NOT position as:
- "Indie Game Developer"

Position as:
- C++ Simulation Engineer
- Systems Engineer (Real-Time / Interactive)
- Graphics & Simulation Developer

Core identity:
> Systems-first engineer who builds and debugs complex, emergent simulations

---

## Target Roles

High-value roles:

- Engine Programmer
- Simulation Engineer (Games, Robotics, Defense, HPC)
- Graphics / Rendering Engineer
- Physics / Systems Engineer

---

## Compensation Expectations

Full-time:
- Mid: $100k – $180k
- Senior: $150k – $250k+

Contract:
- $70 – $150/hr typical
- $90 – $180/hr for specialized simulation work

---

## What Studios Actually Need

- Engineers who understand systems, not just features
- Ability to debug emergent behavior
- Performance-aware C++ development
- Strong mental model of complex interactions

---

## Portfolio Strategy

Build artifacts from the simulation project:

- Demo videos (VERY important)
- GitHub repo (clean architecture)
- Technical writeups (how systems work)

Key demonstration areas:
- Multi-layer simulation
- Control systems (AND logic, thresholds)
- Emergent behavior
- Debugging tools and overlays

---

## Contracting Strategy

Focus on niche specialization:

- Simulation systems
- Performance optimization
- Engine architecture
- Rendering / visualization
- Debugging complex failures

Goal:
> Become the engineer called when systems stop behaving correctly

---

## Strategic Insight

Do not rely on:
- game sales

Leverage:
- the project as a **career accelerator**

Best framing:
> Build a simulation platform that can also become a game
