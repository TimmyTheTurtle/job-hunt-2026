# RESUME BULLET RULES FOR CODEX

## Objective

Write resume bullets that are concrete, honest, and outcome-oriented.

## Preferred verbs

- built
- designed
- implemented
- integrated
- maintained
- deployed
- improved
- automated
- supported
- translated
- configured
- delivered
- streamlined

## Bullet requirements

Each bullet should be:
- specific
- grounded
- concise
- believable
- relevant to the target role

## Preferred bullet patterns

- Built X to support Y workflow, enabling Z outcome.
- Implemented X logic for Y domain constraint.
- Maintained and deployed X across Y environment.
- Translated complex business/process requirements into X.
- Integrated X with Y to support operational needs.

## Good source material from Dorian's background

- CPQ/configuration logic
- quoting and estimation workflows
- survey/configuration interfaces
- IIS / Azure deployment
- e-commerce/plugin integration
- insurance/business-rules thinking
- small-business technical ownership
- Google Ads operational experience where relevant

## Constraints

Do not invent numbers, scale, or outcomes.
Use measurable language only when actually supported.
Prefer understated credibility over inflated claims.
