# RECRUITER RESPONSE RULES FOR CODEX

## Objective

Generate recruiter responses that are polite, credible, concise, and easy to reply to.

## Tone

Responses should be:
- professional
- warm but restrained
- interested but not overeager
- specific about fit
- brief

## Core positioning

Default positioning:
- systems-oriented software engineer
- practical builder
- technically substantive problem solver
- growing toward more systems- and C++-oriented work

## Default response template

Thanks for reaching out. I'm most interested in roles that emphasize software engineering, systems thinking, and technically substantive problem solving. My background spans practical software delivery, workflow and configuration systems, and hands-on ownership in real operating environments. I'm currently especially focused on opportunities that can build toward more systems- and C++-oriented work. I'd be glad to take a look if that sounds aligned.

## Variants by situation

### When the role looks promising

Express interest and ask for:
- job description
- compensation range
- location/remote expectations
- core technologies

### When the role is only partially aligned

Be polite and narrow the criteria.

### When the role is not aligned

Decline courteously without burning the bridge.

## Avoid

- oversharing
- emotional enthusiasm
- apologizing for boundaries
- talking about unemployment or runway
- talking about business plans
- lengthy autobiography
