# Interview Prep

## Company Research
- Mission: Position themselves as a training-and-placement partner that helps candidates become client-ready for technical roles.
- Recent News: The posting references Oracle Cloudworld 2023 and Gartner Data & Analytics Summit participation; verify current details if contacted.
- Key Products: Candidate training, upskilling, and placement services for client-facing software roles.

## Role-Specific Prep
- Technical skills to highlight:
  - C++
  - object-oriented development
  - debugging and reverse engineering in layered systems
  - SQL and backend data reasoning
  - willingness to ramp on Java, REST APIs, Docker, Jenkins, and cloud tooling
- Projects to discuss:
  - enterprise C# / SQL customization work in a complex system
  - any C++ practice or projects
  - aerospace / systems-analysis work that required structured debugging and disciplined problem solving

## Questions to Ask Them
1. Is this opening for SynergisticIT directly or for a specific client engagement?
2. Which technologies are actually primary on day one: Java, C++, Spring, or cloud platform work?
3. What training, evaluation, and onsite expectations apply before client placement?

## STAR Stories Ready
1. Reverse engineered a poorly documented system and shipped a working solution.
2. Diagnosed a complex data or telemetry issue with structured analysis.
3. Learned a new technical domain quickly and delivered under ambiguity.
